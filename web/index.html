            What goes into the configuration?
          
          

            

              
Finite domains

              

                Use domains for arguments you want to explore: for example, n:
                [0, 1, 2, 11, 0.1]. Coverage applies only to these values and
                any representatives listed in the report.
              

            

            

              
Sample values

              

                Use samples for plain interpolations such as name. The same
                catalog is rendered for every requested locale; messages are not
                translated.
              

            

            

              
Explicit limits

              

                The engine bounds input, vectors, and output. A limit failure
                discards the whole run. Reduce a domain, split the catalog, or
                remove a stricter limits override.
